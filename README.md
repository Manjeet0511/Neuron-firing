# Neural Response to Visual Stimuli — EEG Analysis of Flanker Conditions
[![DOI](https://img.shields.io/badge/DOI-10.3126%2Fhp.v12i1.77191-blue)](https://doi.org/10.3126/hp.v12i1.77191)

This repository contains the code, figures, and documentation supporting the research paper:

**"Analyzing neural response to visual stimuli: Firing rates, frequency band dynamics, and synchrony in near and far flanker conditions"**
*Manjeet Kunwar, Nabin Bhusal, Niraj Dhital*
*Published in Himalayan Physics, Vol. 12 (2025)*

## 🧠 Overview

This study investigates how spatial configurations of visual distractors (flankers) influence EEG-derived neural activity. It contrasts **Near** and **Far** flanker conditions using open-access EEG data from OpenNeuro. Our multimodal analysis includes:

* Spectrograms and wavelet transforms
* Firing rate estimations from EEG spike-like events
* Frequency band power (delta to gamma)
* Cross-correlation analysis to assess inter-regional synchrony

## 📊 Key Findings

* **Near condition**: Elevated delta/theta power, increased spike clustering, higher cognitive load
* **Far condition**: Higher alpha/beta activity, more efficient processing
* No statistically significant difference in mean firing rate (p = 0.735), but spectral and synchrony metrics show meaningful divergence.

## 🧪 Datasets Used

We used EEG data from OpenNeuro:

* [Flankers-FAR (ds005868.v1.0.1)](https://doi.org/10.18112/openneuro.ds005868.v1.0.1)
* [Flankers-NEAR (ds005866.v1.0.1)](https://doi.org/10.18112/openneuro.ds005866.v1.0.1)

Data were collected at SDSU's NeuroCognition Lab under IRB compliance.
